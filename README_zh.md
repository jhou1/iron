# iron

[English](README.md) | 中文版

一款用于追踪训练记录的终端 UI 应用。你可以逐组记录练习、回顾历史数据，并直观地查看你的训练频率与一致性。所有数据均安全地保存在本地的一个 SQLite 文件中。

![](docs/iron.jpg)

## 理念

- **原生终端体验**：全键盘驱动，响应迅速，让你专注于训练本身。
- **本地优先**：你的数据只属于你，仅保存在 `~/.iron/iron.db` 中。
- **极简主义**：无需注册账号，没有复杂的同步机制，拒绝臃肿功能——回归纯粹的训练记录。

## 核心功能

- **逐组记录**：支持重量自动顺延，可记录热身/放松阶段及训练备注。
- **高效修改**：对于已记录的组，可以直接修改或删除，无需重填整条记录。
- **历史记录**：支持过滤筛选，提供内联的详细信息弹窗，并支持编辑、删除及撤销操作。
- **训练趋势**：针对每项练习提供迷你图表（sparkline charts），可自由调整时间窗口。
- **贡献热力图**：在主面板展示类似 GitHub 的训练热力图。
- **目标与里程碑**：通过进度条直观展示目标的达成情况。
- **每日格言**：主面板每日展示格言，可通过专门的界面进行管理。
- **HRV 追踪**：每天早晨记录 0–100 的心率变异性得分。
- **4 种练习类型**：计重×次数（Weight x Reps）、仅计次数（Reps Only）、距离（Distance, km）和时长（Duration, min）。
- **数据备份**：支持导出和导入 JSON 格式文件。
- **Vim 风格导航**：支持 `j/k`、`h/l`、`/`、`Enter`、`Esc`，且文本输入支持 Emacs 快捷键（`Ctrl+A/E/B/F/K`）。
- **多语言支持**：提供英语和简体中文界面。

## 安装

系统需安装 Rust 1.70+ 版本。

```bash
git clone https://github.com/jhou1/iron.git
cargo build --release
cp target/release/iron ~/.local/bin/
```

## 运行与使用

```bash
iron                   # 英文界面
LANG=zh_CN.UTF-8 iron  # 中文界面
```

### 导航与界面重新进入

现有的 Dashboard 导航路径和快捷键保持不变。打开 Dashboard、History、Trends、Practices、Goals 或 Quotes 时，应用会先重新读取数据库中的最新数据，再切换界面。在适用的界面中，会通过稳定 ID 恢复同一条目，并保留当前筛选条件、视口、已聚焦的详情以及 Trends 的时间窗口。重新进入界面时，未完成的新增、编辑、日期修改和删除确认状态、旧状态消息以及跨界面的撤销数据都会被清除。

从 History 编辑记录时，导航会携带所选训练记录的稳定 ID，因此即使数据发生变化，Log Entry 也会打开准确的目标记录。目标准备是原子的：如果目标界面刷新失败，应用会停留在来源界面，保留其当前状态和缓存的目标界面，并显示错误。Batch 3A 已交付这套生命周期行为。Batch 3B-1 仅迁移 Practices 的呈现层；其他界面保持不变，后续切片尚未交付。

### 仪表盘 (Dashboard)

主界面的仪表盘会展示 52 周热力图、每周概览与连续训练天数、近期活动、当前目标、每日格言和今日 HRV。响应式布局会在支持的 `80x35` 尺寸下把内容限制在各自面板内，并保证更小的直接渲染区域也不会越界。

| 快捷键 | 动作 |
|-------|-------------------------|
| `l`   | 记录一条训练 |
| `h`   | 历史记录 |
| `t`   | 训练趋势 |
| `e`   | 练习项目管理 |
| `g`   | 目标 |
| `Q`   | 每日格言管理 |
| `v`   | 记录今日 HRV |
| `Esc` | 退出 |

底部快捷键始终只描述当前模式：输入 HRV 时仅显示确认/取消，退出确认时仅显示确认操作。HRV 必须是 0 到 100 的整数；校验失败或数据库写入失败时，编辑模式和已输入的值都会保留，并显示错误状态。

### 首次使用设置

1. 按 `e` 进入 **Practices (练习)** 界面。
2. 按 `a` 添加一项练习，输入名称后按回车。
3. 使用 `j/k` 选择练习类型，然后按回车确认：
   - **Weight x Reps** — 记录重量（kg）和次数。
   - **Reps Only** — 仅记录次数（如自重训练）。
   - **Distance** — 记录距离（公里）。
   - **Duration** — 记录时长（分钟）。
4. 按 `Esc` 返回主面板。

### 记录训练 (Logging)

在主界面按 `l` 进入记录界面。

1. 使用 `j/k` 选择或过滤练习项目，按回车选中。
2. 输入每组的数据：
   - 输入重量，按 `Tab` 切换至次数，输入次数后按 `Enter` 提交。
   - 对于负重练习，重量会自动顺延；你只需输入次数并按 `Enter`。
3. 按 `Tab` 键在不同部分间循环切换：组数 → 热身 → 放松 → RPE → 备注。
4. 使用 `j/k` 在已记录的组之间导航；按 `e` 修改，按 `d` 删除。
5. 按 `D` 可修改本次训练的日期。
6. 仅当至少一组已提交，且没有正在进行的组编辑或日期编辑时，`Ctrl+S` 才会保存整条记录。
7. 按 `Esc` 取消。

练习选择器会在第一项和最后一项处停止；当可视区域外仍有结果时，标题会显示 `↑`、`↓` 或 `↑↓`。所有单行输入都会水平滚动，让 Unicode 光标保持可见。底部快捷键会随过滤、当前字段、组编辑、日期编辑和退出确认模式动态变化。校验或数据库保存失败时，表单、光标、焦点和返回目标都会保留，并显示错误状态。

### 历史记录 (History)

按 `h` 进入。列表会在可换行的详情面板中预览所选记录；按 `Enter` 聚焦并滚动完整详情。

| 快捷键 | 动作 |
|---|---|
| `j/k` | 上下移动 |
| `Enter` | 聚焦所选详情；聚焦后用 `j/k` 滚动 |
| `/` | 按练习名称筛选 |
| `e` | 编辑记录 |
| `d` | 删除记录 |
| `u` | 撤销上次删除 |
| `Esc` | 返回 |

### 训练趋势 (Trends)

按 `t` 进入。选中一项练习即可查看它的趋势图表。

| 快捷键 | 动作 |
|---|---|
| `j/k` | 在练习列表中导航 |
| `h/l` | 调整时间窗口 (±30 天，范围在 30–365 天之间) |
| `/` | 过滤练习项目 |
| `Esc` | 返回 |

### 练习项目管理 (Practices)

按 `e` 管理你的练习清单。

| 快捷键 | 动作 |
|---|---|
| `j/k` | 上下移动 |
| `a` | 添加练习 |
| `e` | 重命名 |
| `Space` | 切换 激活/隐藏 状态 |
| `d` | 删除 |
| `Esc` | 返回 |

较长的练习名称不会越出列表；添加、重命名或删除失败时会保留当前表单并显示错误。

### 目标 (Goals)

按 `g` 进入。

目标列表：

| 快捷键 | 动作 |
|---|---|
| `j/k` | 在目标间导航 |
| `a` | 添加目标 |
| `e` | 重命名选中的目标 |
| `Enter` | 聚焦所选目标的里程碑面板 |
| `m` | 直接添加里程碑 |
| `Space` | 切换无里程碑目标的完成状态 |
| `D` | 编辑已完成目标的日期 |
| `d` / `u` | 删除 / 撤销删除 |
| `Esc` | 返回 Dashboard |

里程碑面板：

| 快捷键 | 动作 |
|---|---|
| `j/k` | 遍历所有里程碑，面板按需滚动 |
| `a` | 添加里程碑 |
| `Enter` / `e` | 重命名选中的里程碑 |
| `Space` | 切换完成状态并刷新目标进度 |
| `D` | 编辑已完成里程碑的日期 |
| `d` / `u` | 删除 / 撤销删除 |
| `Esc` | 返回目标列表 |

有里程碑的目标会显示“已完成数/总数 · 百分比”，目标完成状态由里程碑状态自动推导。

### 每日格言管理 (Quotes)

按 `Q` 进入。列表行保持紧凑，同时在可换行的面板中完整预览所选格言。

| 快捷键 | 动作 |
|---|---|
| `j/k` | 在格言间导航 |
| `Enter` | 聚焦完整预览；聚焦后用 `j/k` 滚动 |
| `a` / `e` | 添加 / 编辑格言 |
| `d` / `u` | 删除 / 撤销删除 |
| `Esc` | 退出详情聚焦或返回 |

## 数据与备份

所有数据存储在 `~/.iron/iron.db` (SQLite 数据库) 中。你可以通过复制该文件或使用 JSON 导出功能进行备份：

```bash
iron export backup.json
iron import backup.json    # 导入时会自动跳过重复数据
```

应用在首次启动时会自动将旧版本 `~/.ironcli/` 目录中的数据迁移过来。

Quick Log 及其 LLM 配置与运行时代码已永久移除，且没有替代工作流。配套的 Abbreviations API 和数据表也已移除：打开现有数据库时会删除 `abbreviations` 表并永久删除其中的数据，同时保留训练记录、练习、目标、格言、HRV 及其他无关数据。
